# 设计

基于 jim-uiux 1.3.0（https://design.linjiejim.com）。本文只记录和默认值不同的地方。

## 旋钮

- 强调色：靛蓝，浅色 `#4b57d6`，深色 `#8f98ff`（`src/styles/retrace.css`）
- 圆角：默认 8
- 密度：紧凑（`<html data-density="compact">`），桌面工具，信息密度优先
- 默认外观：跟随系统

## 项目 token（`src/styles/retrace.css`）

| Token | 用途 |
| --- | --- |
| `--lane-0` | 集成分支车道，等于 `--primary` |
| `--lane-1` … `--lane-6` | 其他分支车道，浅色、深色各一套，对画布 ≥ 3:1；「彩色」「字母」文件图标主题也用它们给文件类型着色 |
| `--diff-*` | diff 增删底色，由 `--success` / `--destructive` 混入画布 |

## 例外

- 提交图和改动树的行高 26px（低于 `--row-h`），因为单行提交图是核心需求；行内文字仍 ≥ 12px。
- diff 里删除行用红色底：这是 diff 的通用约定，不表示错误。
- 车道用 7 种颜色：这是分类数据，不是强调色。文件图标按类型着色同理。
- 折叠合并时，合并行前多一个 ▸ / ▾ 展开按钮（20px，悬停才有底色，带 Tooltip 和 `aria-expanded`），点它不选中这一行；折叠的合并行代表整条分支，主题文字不像普通 merge 提交那样降成次要色。
- 其他分支收成一行时，节点画成两层叠起的小方块（表示后面还有提交），分支名标签用车道色文字 + 14% 车道色底，好和普通分支标签区分；▸ / ▾ 按钮同合并行。
- 搜索框尾部的「也搜提交说明正文」开关做成框内 20px 图标按钮（`aria-pressed`，打开时 `--primary-subtle` 底），不另占一栏。
- 置顶的项目列在最上面，标题「已置顶」是个没有名字、没有菜单、不能拖动的伪分组；真分组按住标题拖动排序，单击仍是折叠。新建分组先用小弹框起名，不再先建「新分组」再改名。
- 每块视图标题栏左边的拖动把手平时隐藏，悬停标题栏时出现：四块视图都有，常显会很吵；把手有 Tooltip 和无障碍名称。
- 视图之间用 1px 分隔线（不是卡片），符合「细线不用阴影」；拖动停靠时的预览用 `--primary-subtle` 填充 + 2px `--primary` 描边。
- 设置、布局和视图开关放在 macOS 菜单栏，不在页面上：页面只留看代码要用的东西；菜单项和快捷键见 README。
- 每块视图有自己的最小尺寸（项目 160 × 96、改动 220 × 140、提交图和 diff 320 × 140/160），窄的时候标题栏先收起文字和次要开关（它们在菜单栏里都有），关闭按钮始终可见。
- 文件预览里的 Markdown 用一套接近 GitHub 的排版（`.markdown`，正文 14px、行高 1.7、标题带分隔线），因为读的是仓库文档，不是界面文字；颜色、圆角、等宽字体仍取 token。
- 预览图片的透明部分用棋盘格（`.bg-checker`，`--muted` 与 `--background` 交替），这是看图的通用约定。
- Agent 会话是右侧浮出的非模态抽屉（宽默认 `min(60vw, 960px)`，左边缘可拖，双击还原），不占布局里的一块：窗口本来就挤，会话只在需要时盖在提交图和 diff 上面；左侧项目栏始终可点，用来切换会话。用 ✕、⌘T、Esc 或再点一次左侧那个会话收起（焦点在终端里时 Esc 交给 agent，那是它的「打断」），点抽屉外面不收起。抽屉是最上面一层，Esc 先收它，再关 diff。
- 抽屉里是两种内容之一。能说 ACP 的 agent（OpenCode）是 Retrace 自己画的对话：一列最宽 760px；每一轮只有你的话（右侧的灰底块）、agent 的回答（`.markdown` 紧凑排版）和这一轮改动的文件（带增删行数的小按钮，点开就是 Retrace 的 diff），过程折成一行摘要，展开才是逐步清单。权限请求是输入框上方的一条 `--warning-subtle` 底色的卡片（黄色 = 该你了），按钮用 agent 给的选项，第一项「允许一次」是唯一的主按钮；卡片不抢焦点，免得正在打字时回车把命令批准了。输入框下面一行是 agent 报上来的配置项（模型、模式、思考强度），各一个幽灵按钮 + 弹出列表，超过 12 项带筛选框。其余 agent 是它自己的终端界面。
- 终端配色取 `--background`、`--foreground`、`--primary`（选区 28% 透明）；ANSI 16 色用 xterm 默认，因为那是 agent 自己的配色。
- 会话状态图标：转圈 = 运行中，黄色圆点 = 等你回应，黄色问号 = 等你确认（agent 在要权限或问问题；黄色都表示「该你了」），红色三角 = agent 报错了但还开着，绿色对勾 = 已结束，灰色方块 = 你停止的，红色叹号 = 进程出错退出；形状各不相同，悬停有文字（等你确认和报错会带上是哪条命令、什么错）。问号和三角只有对话会话才有（agent 自己报状态，目前是 OpenCode），终端会话这两种情况都显示成黄色圆点。
