# 设计

基于 jim-uiux 1.3.0（https://design.linjiejim.com）。本文只记录和默认值不同的地方。

## 旋钮

- 强调色：靛蓝，浅色 `#4b57d6`，深色 `#8f98ff`（`src/styles/retrace.css`）
- 圆角：默认 8
- 密度：紧凑（`<html data-density="compact">`），桌面工具，信息密度优先
- 默认外观：跟随系统

## 项目 token（`src/styles/retrace.css`）

| Token | 用途 |
| --- | --- |
| `--lane-0` | 集成分支车道，等于 `--primary` |
| `--lane-1` … `--lane-6` | 其他分支车道，浅色、深色各一套，对画布 ≥ 3:1；「彩色」「字母」文件图标主题也用它们给文件类型着色 |
| `--diff-*` | diff 增删底色，由 `--success` / `--destructive` 混入画布 |

## 例外

- 提交图和改动树的行高 26px（低于 `--row-h`），因为单行提交图是核心需求；行内文字仍 ≥ 12px。
- diff 里删除行用红色底：这是 diff 的通用约定，不表示错误。
- 车道用 7 种颜色：这是分类数据，不是强调色。文件图标按类型着色同理。
- 每块视图标题栏左边的拖动把手平时隐藏，悬停标题栏时出现：四块视图都有，常显会很吵；把手有 Tooltip 和无障碍名称。
- 视图之间用 1px 分隔线（不是卡片），符合「细线不用阴影」；拖动停靠时的预览用 `--primary-subtle` 填充 + 2px `--primary` 描边。
- 设置、布局和视图开关放在 macOS 菜单栏，不在页面上：页面只留看代码要用的东西；菜单项和快捷键见 README。
- 每块视图有自己的最小尺寸（项目 160 × 96、改动 220 × 140、提交图和 diff 320 × 140/160），窄的时候标题栏先收起文字和次要开关（它们在菜单栏里都有），关闭按钮始终可见。
- 文件预览里的 Markdown 用一套接近 GitHub 的排版（`.markdown`，正文 14px、行高 1.7、标题带分隔线），因为读的是仓库文档，不是界面文字；颜色、圆角、等宽字体仍取 token。
- 预览图片的透明部分用棋盘格（`.bg-checker`，`--muted` 与 `--background` 交替），这是看图的通用约定。
